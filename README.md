# thewhitebox.com

One static page: The White Box is the manager of Dansk Design Invest A/S and
sends visitors on to danskdesigninvest.dk. Plain HTML/CSS, no build step, no
JavaScript, no third-party requests. Hosted on Vercel; vercel.json holds the
redirects from the old WordPress URLs and the security headers.

Preview locally with any static server, for example: npx serve .
